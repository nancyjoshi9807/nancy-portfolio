# Nancy Joshi — Portfolio Website

A responsive, single-page personal portfolio built with HTML and CSS.

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing
- Replace `your-email@example.com` with your email address.
- Replace the GitHub and LinkedIn profile links with your own URLs.
- Update the project cards as you complete and publish real work.

## Publish with GitHub Pages
1. Create a public GitHub repository named `nancy-portfolio`.
2. Upload `index.html`, the `assets` folder, and this README.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The website URL will appear in the Pages section.
